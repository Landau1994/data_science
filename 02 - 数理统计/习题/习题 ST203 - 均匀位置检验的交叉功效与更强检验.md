# 习题 ST203：均匀位置检验的交叉功效与更强检验

## 题目

### 英文原题

> [!question] 英文原题
> **8.13** Let $X_1,X_2$ be iid uniform$(\theta,\theta+1)$. For testing $H_0:\theta=0$ versus $H_1:\theta>0$, we have two competing tests:
> $$\phi_1(X_1):\quad\text{Reject }H_0\text{ if }X_1>.95,$$
> $$\phi_2(X_1,X_2):\quad\text{Reject }H_0\text{ if }X_1+X_2>C.$$
> (a) Find the value of $C$ so that $\phi_2$ has the same size as $\phi_1$.
> (b) Calculate the power function of each test. Draw a well-labeled graph of each power function.
> (c) Prove or disprove: $\phi_2$ is a more powerful test than $\phi_1$.
> (d) Show how to get a test that has the same size, but is more powerful than $\phi_2$.

### 中文转述

> [!question] 中文转述
> **原题8.13。**
> 设 $X_1,X_2$ 独立同分布于 $\operatorname{uniform}(\theta,\theta+1)$. 对检验 $H_0:\theta=0$ 对 $H_1:\theta>0$，有两个候选检验：
>
> $$
> \begin{aligned}\phi_1(X_1):&\quad X_1>.95\text{ 时拒绝 }H_0,\\
> \phi_2(X_1,X_2):&\quad X_1+X_2>C\text{ 时拒绝 }H_0.\end{aligned}
> $$
>
> (a)  求 $C$，使 $\phi_2$ 与 $\phi_1$ 大小相同.
>
> (b)  计算各检验的功效函数，并画出标注清楚的图像.
>
> (c)  证明或否证：$\phi_2$ 比 $\phi_1$ 功效更高.
>
> (d)  说明如何得到与 $\phi_2$ 大小相同、但功效更高的检验.

## 提示

> [!hint]- 提示
> 平移后两均匀变量的和有三角形密度；支持超出原假设可免费拒绝。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 只需$\theta\ge0$。写$X_i=\theta+U_i$，$U_i$独立$U(0,1)$。
> (a) $\phi_1$的大小$.05$。当$1<C<2$时$P_0(U_1+U_2>C)=(2-C)^2/2$，故$C=2-\sqrt{.1}$。
> (b) $\beta_1(\theta)=\min(1,\theta+.05)$。令$F_2(t)$在$t\le0$为0，在$0<t\le1$为$t^2/2$，在$1<t<2$为$1-(2-t)^2/2$，在$t\ge2$为1，则$\beta_2(\theta)=1-F_2(C-2\theta)$。这些分段式包括全部转折点。
> (c) 令$a=\sqrt{.1}$。当$0\le\theta\le(C-1)/2$时，两者差为$\theta(2\theta+2a-1)$；它在$0<\theta<(1-2a)/2$为负，例如$\theta=.1$时$\beta_2\approx.13325<.15=\beta_1$。而在$\theta=.5$时$\beta_2\approx.76623>.55$，所以功效交叉，不存在题述一致优越。
> (d) 取$k=1-\sqrt{.05}$，拒绝当$\max(X_1,X_2)>1$或$\min(X_1,X_2)>k$，记为$\phi_3$。在原假设下第一部分概率0，第二部分概率$(1-k)^2=.05$。其功效为$\beta_3(\theta)=.05+2\theta-\theta^2$（$0\le\theta<k$），及1（$\theta\ge k$）。证明其UMP性：对固定$0<\theta<k$，原假设支持外的备择概率可全拒绝且不付出大小；两支持交集内密度比恒1，任何大小$.05$的检验至多再贡献$.05$功效，而$\phi_3$的原假设拒绝小方块完全处于备择支持内，达到此界。$\theta\ge k$时它功效1亦最优。因此它支配$\phi_2$并在一些点严格更强。
>
