# 习题 ST248：不等误判代价正态检验的极小极大水平

## 题目

### 英文原题

> [!question] 英文原题
> **8.58** Consider the hypothesis testing problem and loss function given in Example 8.3.31 and let $\sigma=n=1$. Consider the test that rejects $H_0$ if $X<-z_\alpha+\theta_0$. Find the value of $\alpha$ that minimizes the maximum value of the risk function, that is, yields a minimax test.

### 中文转述

> [!question] 中文转述
> **原题8.58。**
> 考虑例8.3.31的假设检验问题和损失函数，令 $\sigma=n=1$. 考虑在 $X<-z_\alpha+\theta_0$ 时拒绝 $H_0$ 的检验. 求使风险函数最大值最小的 $\alpha$，即得到极小极大检验（minimax test）的 $\alpha$.

## 提示

> [!hint]- 提示
> 先重述原例两种误判代价，再平衡原假设边界与备择边界的最坏风险。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 原例为$H_0:\theta\ge\theta_0$对$\theta<\theta_0$，加权0–1误判损失$c_I=8,c_{II}=3$。当$\sigma=n=1$，令$d=\theta-\theta_0$，功效$\beta(d)=\Phi(-z_\alpha-d)$。风险为$8\beta(d)$若$d\ge0$，为$3[1-\beta(d)]$若$d<0$。第一部分随$d$下降，最大值在0为$8\alpha$；第二部分随$d$向0增加，其上确界为$3(1-\alpha)$，可能只在$0-$逼近。因此全空间最坏风险为$M(\alpha)=\max\{8\alpha,3(1-\alpha)\}$。
> 第一条直线递增、第二条递减，最大者的唯一最小点在二者相等：$8\alpha=3(1-\alpha)$，得到$\alpha=3/11$，最坏风险$24/11$。阈值为$\theta_0-\Phi^{-1}(8/11)$。
> 它也在全部检验中极小极大：任意检验令边界拒绝概率为$a$；正态位置族下有界检验的功效随位置连续，所以其全局最坏风险至少$\max\{8a,3(1-a)\}\ge24/11$。上述规则达到这个下界，故不只是阈值类内最优。这里用的是原例加权0–1损失，不能误用紧随其后的(8.3.13)随参数变化损失。
