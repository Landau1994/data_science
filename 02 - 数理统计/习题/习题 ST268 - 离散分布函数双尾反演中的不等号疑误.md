# 习题 ST268：离散分布函数双尾反演中的不等号疑误

## 题目

### 英文原题

> [!question] 英文原题
> **9.20** Some of the details of the proof of Theorem 9.2.14 need to be filled in, and the second part of the theorem needs to be proved.
> (a) Show that if $F_T(T|\theta)$ is stochastically greater than or equal to a uniform random variable then so is $\overline F_T(T|\theta)$. That is, if $P_\theta(F_T(T|\theta)\le x)\le x$ for every $x$, $0\le x\le1$, then $P_\theta(\overline F_T(T|\theta)\le x)\le x$ for every $x$, $0\le x\le1$.
> (b) Show that for $\alpha_1+\alpha_2=\alpha$, the set $\{\theta:F_T(T|\theta)\le\alpha_1\text{ and }\overline F_T(T|\theta)\le\alpha_2\}$ is a $1-\alpha$ confidence set.
> (c) If the cdf $F_T(t|\theta)$ is a decreasing function of $\theta$ for each $t$, show that the function $\overline F_T(t|\theta)$ defined by $\overline F_T(t|\theta)=P(T\ge t|\theta)$ is a nondecreasing function of $\theta$ for each $t$.
> (d) Prove part (b) of Theorem 9.2.14.

### 中文转述

> [!question] 中文转述
> **原题9.20。**
> 需要补全定理9.2.14证明中的一些细节，并证明定理的第二部分.
>
> (a)  证明：若$F_T(T\mid\theta)$随机大于或等于均匀随机变量，则$\overline F_T(T\mid\theta)$也如此. 即若对每个$0\le x\le1$都有$P_\theta(F_T(T\mid\theta)\le x)\le x$，则对每个$0\le x\le1$也有$P_\theta(\overline F_T(T\mid\theta)\le x)\le x$.
>
> (b)  证明：对于$\alpha_1+\alpha_2=\alpha$，集合$\{\theta:F_T(T\mid\theta)\le\alpha_1\text{ 且 }\overline F_T(T\mid\theta)\le\alpha_2\}$是$1-\alpha$置信集.
>
> (c)  若cdf $F_T(t\mid\theta)$对每个$t$均为$\theta$的递减函数，证明由$\overline F_T(t\mid\theta)=P(T\ge t\mid\theta)$定义的函数$\overline F_T(t\mid\theta)$，对每个$t$均为$\theta$的非递减函数.
>
> (d)  证明定理9.2.14的(b)部分.

## 提示

> [!hint]- 提示
> 保留$P(T<t)$与$P(T\le t)$的差别；先用连续均匀例检查(b)原列两个“$\le$”是否给出中央接受域，再讨论离散端点。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 教材输入与补充假设另行标明。
>
> (a) 对任意离散$T$，$\overline F_T(T)=F_{-T}(-T)$。任意分布函数$H$都满足$P(H(V)\le x)\le x$：集合$\{v:H(v)\le x\}$为下区间，其累积概率至多$x$，可用区间端点的极限证明，允许无有限最大点。因此对$-T$直接应用即得结论，无须仅由$1-F(T)$推导（后者会漏原子质量）。
> (b) 原式错误。例如退化$T=0$时两尾函数都为1，原集合对$\alpha_i<1$为空，覆盖0。应保留**大尾概率**：$C(t)=\{\theta:F_T(t|\theta)>\alpha_1,\overline F_T(t|\theta)>\alpha_2\}$。其不覆盖事件包含于两个小尾事件的并，概率至多$\alpha_1+\alpha_2$；把$>$改$\ge$只会扩大集合，仍有效。原正文PDF382同有相反不等号，已显式记录，不静默修正。
> (c) $\overline F_T(t|\theta)=1-F_T(t^-|\theta)$。$F_T(t^-|\theta)=\lim_{s\uparrow t}F_T(s|\theta)$随$\theta$非增，故其补非减。
> (d) 若$F$随$\theta$非减，$\overline F$非增。定理第二种情形端点满足$F_T(t|\theta_L)=\alpha_2$、$\overline F_T(t|\theta_U)=\alpha_1$。若$\theta<\theta_L(t)$，有$F_T(t|\theta)\le\alpha_2$；若$\theta>\theta_U(t)$，有$\overline F_T(t|\theta)\le\alpha_1$。两种越界概率之和至多$\alpha_2+\alpha_1$，故闭区间覆盖至少$1-\alpha$。方程无解时需以参数边界和广义逆补端点；单调不严格时不主张唯一。
