# 习题 ST073：正态接受拒绝的柯西与双指数包络

## 题目

### 英文原题

> [!question] 英文原题
> **5.62** Find the values of $M$ so that an accept/reject algorithm can generate $Y\sim\operatorname n(0,1)$ using $U\sim\operatorname{uniform}(0,1)$ and
>
> (a) $V\sim\text{Cauchy}$.
>
> (b) $V\sim\text{Double Exponential}$.
>
> (c) Compare the algorithms. Which one do you recommend?

### 中文转述

> [!question] 中文转述
> **原题5.62。** 求使接受／拒绝算法可以用$U\sim\operatorname{uniform}(0,1)$和下列$V$生成$Y\sim n(0,1)$的$M$.
>
> (a)  $V\sim\operatorname{Cauchy}$.
>
> (b)  $V$服从双指数分布.
>
> (c)  比较两种算法.你推荐哪一种？

## 提示

> [!hint]- 提示
> 最大化φ(v)/g(v)，利用对称性只求v≥0。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 取标准柯西$g_C(v)=1/[\pi(1+v^2)]$和标准双指数（Laplace）$g_L(v)=e^{-|v|}/2$，目标$\phi(v)$。
>
> **(a)** 比值$R_C(v)=\sqrt{\pi/2}(1+v^2)e^{-v^2/2}$。对$v>0$求对数导数为$2v/(1+v^2)-v=v(1-v^2)/(1+v^2)$，故全局最大在$v=\pm1$，$M_C=\sqrt{2\pi/e}\approx1.520347$，接受率$1/M_C\approx.657745$。
>
> **(b)** $R_L(v)=\sqrt{2/\pi}\exp(|v|-v^2/2)$，$|v|-v^2/2=1/2-(|v|-1)^2/2$，所以$M_L=\sqrt{2e/\pi}\approx1.315489$，接受率$\sqrt{\pi/(2e)}\approx.760173$。
>
> **(c)** 每轮独立抽$V$和$U$，若$U\le\phi(V)/(M g(V))$便接受。仅按平均候选次数比较，双指数需要1.3155轮、柯西1.5203轮，推荐双指数。它可由$\pm(-\log U)$的随机符号指数生成；实际运行时间还取决于对数、正切及随机数成本，本比较未计时，不能仅凭$M$声称所有实现都更快。
