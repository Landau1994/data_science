# 习题 ST209：指数变量幂观测下双尾最强检验

## 题目

### 英文原题

> [!question] 英文原题
> **8.19** The random variable $X$ has pdf $f(x)=e^{-x}$, $x>0$. One observation is obtained on the random variable $Y=X^\theta$, and a test of $H_0:\theta=1$ versus $H_1:\theta=2$ needs to be constructed. Find the UMP level $\alpha=.10$ test and compute the Type II Error probability.

### 中文转述

> [!question] 中文转述
> **原题8.19。**
> 随机变量 $X$ 的密度为 $f(x)=e^{-x}$，$x>0$. 观察随机变量 $Y=X^\theta$ 一次，需构造 $H_0:\theta=1$ 对 $H_1:\theta=2$ 的检验. 求水平 $\alpha=.10$ 的一致最强检验，并计算第二类错误概率.

## 提示

> [!hint]- 提示
> 观察的是幂变量而非原变量，似然比在零附近也很大。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 对$\theta>0$，逆变换$x=y^{1/\theta}$给$f_\theta(y)=\theta^{-1}y^{1/\theta-1}e^{-y^{1/\theta}}$，$y>0$。两简单假设的似然比为$r(y)=e^{y-\sqrt y}/(2\sqrt y)$，其对数导数$1-1/(2\sqrt y)-1/(2y)$在$y<1$为负、$y>1$为正；比值在0和无穷均趋无穷，在1为$1/2$。故Neyman–Pearson检验拒绝当$Y<a$或$Y>b$，其中$0<a<1<b$、$r(a)=r(b)$且$1-e^{-a}+e^{-b}=.10$。这两方程唯一确定临界值：实际括区间求根得到$a\approx.0765460963,b\approx3.637798055$，共同阈值约$1.47943512$。它在原假设下精确大小$.10$，并对题内唯一备择最强，故也是此问题的UMP检验。
> 备择下$Y=X^2$，接受区间等价于$\sqrt a<X<\sqrt b$，所以第二类错误为$e^{-\sqrt a}-e^{-\sqrt b}\approx.609824402$。临界值数值只用于实施，方程及似然比单调分支给出完整理论定义；单纯拒绝大$Y$会漏掉零附近更大似然比而不是最强。
