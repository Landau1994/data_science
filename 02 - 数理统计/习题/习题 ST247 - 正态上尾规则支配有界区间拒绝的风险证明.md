# 习题 ST247：正态上尾规则支配有界区间拒绝的风险证明

## 题目

### 英文原题

> [!question] 英文原题
> **8.57** Consider testing $H_0:\mu\le0$ versus $H_1:\mu>0$ using 0–1 loss, where $X\sim\mathrm n(\mu,1)$. Let $\delta_c$ be the test that rejects $H_0$ if $X>c$. For every test in this problem, there is a $\delta_c$ in the class of tests $\{\delta_c,-\infty\le c\le\infty\}$ that has a uniformly smaller (in $\mu$) risk function. Let $\delta$ be the test that rejects $H_0$ if $1<X<2$. Find a test $\delta_c$ that is better than $\delta$. (Either prove that the test is better or graph the risk functions for $\delta$ and $\delta_c$ and carefully explain why the proposed test should be better.)

### 中文转述

> [!question] 中文转述
> **原题8.57。**
> 设 $X\sim\mathrm n(\mu,1)$，在 $0$–$1$ 损失下考虑检验 $H_0:\mu\le0$ 对 $H_1:\mu>0$. 设 $\delta_c$ 为在 $X>c$ 时拒绝 $H_0$ 的检验. 对本问题的每个检验，类 $\{\delta_c:-\infty\le c\le\infty\}$ 中都存在一个 $\delta_c$，其风险函数关于 $\mu$ 一致更小. 设 $\delta$ 为在 $1<X<2$ 时拒绝 $H_0$ 的检验. 求一个优于 $\delta$ 的 $\delta_c$. （可以证明其优越性，也可以画出 $\delta$ 与 $\delta_c$ 的风险函数，并仔细说明为什么所提出的检验应当更好.）

## 提示

> [!hint]- 提示
> 选上尾规则使它在边界0与原区间检验拒绝概率相同，再用似然比次序比较两侧。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 令$\alpha_0=\Phi(2)-\Phi(1)$，取$c=\Phi^{-1}(1-\alpha_0)$，它在$(1,2)$内。于是$P_0(X>c)=P_0(1<X<2)$。记$D(x)=I(x>c)-I(1<x<2)$，它在$(1,c)$为$-1$、在$(2,\infty)$为1，其余0，且$\int D\phi=0$。
> 对任意$h\in[c,2]$，$r_\mu(x)=f_\mu(x)/f_0(x)=e^{\mu x-\mu^2/2}$。若$\mu>0$，$D(x)[r_\mu(x)-r_\mu(h)]\ge0$处处且在正测集严格正，因此$E_\mu D=\int D(r_\mu-r_\mu(h))f_0>0$。若$\mu<0$，比值递减，同理$E_\mu D<0$。所以备择下上尾规则功效更高、第二类风险更低；原假设负均值下拒绝概率更低、第一类风险也更低；在边界0风险相同。这严格证明$\delta_c$支配$\delta$，无需仅依赖有限图形。原题“一致更小”应按所有参数不增、至少一些严格减理解；不可能在边界校准点还严格较小。
