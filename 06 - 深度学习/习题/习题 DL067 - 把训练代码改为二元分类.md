# 习题 DL067：把训练代码改为二元分类

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 7.17** Change the code in figure 7.8 to tackle a binary classification problem. You will need to (i) change the targets y so they are binary, (ii) change the network to predict numbers between zero and one (iii) change the loss function appropriately.

### 中文转述

> [!question] 中文转述
> 把图7.8改成二元分类：(i)生成二值目标；(ii)让网络预测零到一之间的数；(iii)采用合适的损失。

![[附件/习题图/DS001/原图-7.8.png]]

## 提示

> [!hint]- 提示
> 本解答取每个输入一个二值标签，输出维数改为1，末层加Sigmoid，使用二元交叉熵。

## 解答

> [!success]- 解答
> **独立推导。** 已在[[工具/UDL/experiments/DL066_067.py|可执行训练代码]]的二分类分支实现三项修改：
> (i)设输出维数$D_o=1$，以均匀抽样的0/1生成形状$100\times1$的浮点目标；(ii)输出线性层改成40到1，再接Sigmoid，使预测$p_i\in(0,1)$；(iii)使用BCELoss，即批次平均
> $$
> -\frac1B\sum_{i=1}^B\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
> $$
> 其余设置沿用7.16。若希望直接使用logit且提高数值稳定性，可去掉训练图中的Sigmoid并改用BCEWithLogitsLoss，预测时另取Sigmoid；本次实际运行使用前述显式概率与BCELoss版本。
> 同一环境与种子20261028下，已在CPU单线程运行100轮。首轮批次损失和8.060454，最后一轮0.038726，最终完整训练集平均BCE为0.003872。
> ![[附件/习题图/DS001/DL067-训练损失.png]]
> [[附件/习题图/DS001/DL067-训练记录.csv|逐轮记录]]、[[附件/习题图/DS001/DL067-结果.json|环境与参数]]、[[附件/习题图/DS001/DL067-训练损失.pdf|矢量图]]已保存。这里标签是与输入独立的随机变量，低训练损失体现对有限训练集的拟合，不能解释为学到可泛化的分类规律。
