# 习题 DL106：批归一化的计算图反向传播

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 11.5\*** The forward pass for batch normalization given a batch of scalar values $\{z_i\}_{i=1}^I$ consists of the following operations (figure 11.15):
> $$
> \begin{aligned}
> f_1&=\mathbb E[z_i]& f_5&=\sqrt{f_4+\epsilon}\\
> f_{2i}&=z_i-f_1& f_6&=1/f_5\\
> f_{3i}&=f_{2i}^2& f_{7i}&=f_{2i}\times f_6\\
> f_4&=\mathbb E[f_{3i}]& z_i'&=f_{7i}\times\gamma+\delta,
> \end{aligned}
> \tag{11.10}
> $$
> where $\mathbb E[z_i]=\frac1I\sum_i z_i$. Write Python code to implement the forward pass. Now derive the algorithm for the backward pass. Work backward through the computational graph computing the derivatives to generate a set of operations that computes $\partial z_i'/\partial z_i$ for every element in the batch. Write Python code to implement the backward pass.

## 提示

> [!hint]- 提示
> 均值和方差都依赖整批输入。反向时对共享标量节点的所有入边贡献求和，保留$\epsilon$的位置。

## 解答

> [!success]- 解答
> **独立推导。** 记$n=I$，$\mu=n^{-1}\sum_jz_j$，$c_i=z_i-\mu$，$v=n^{-1}\sum_jc_j^2$，$s=\sqrt{v+\epsilon}$，$r=1/s$，$y_i=\gamma r c_i+\delta$；取$\epsilon>0$。对任意上游梯度$u_i=\partial L/\partial y_i$，按计算图反向：
> $$
> \begin{aligned}
> \bar f_{7i}&=\gamma u_i,&
> \bar f_6&=\sum_i\bar f_{7i}c_i,&
> \bar f_5&=-\bar f_6/s^2,\\
> \bar f_4&=\bar f_5/(2s),&
> \bar f_{3i}&=\bar f_4/n,&
> \bar f_{2i}&=\bar f_{7i}r+2c_i\bar f_{3i},\\
> \bar z_i&=\bar f_{2i}-n^{-1}\sum_j\bar f_{2j},&
> \bar\gamma&=\sum_i u_i r c_i,&
> \bar\delta&=\sum_i u_i.
> \end{aligned}
> $$
> 其中$\bar f_{2i}$同时累计$f_{2i}$到乘法节点及平方节点的两条贡献，最后一项减均值来自$\mu$对全批输入的依赖。利用$\sum_i c_i=0$可化简为
> $$
> \frac{\partial L}{\partial z_i}
> =\frac{\gamma}{s}
> \left(u_i-\bar u-\frac{c_i}{v+\epsilon}\frac1n\sum_j u_jc_j\right).
> $$
> 完整雅可比与题目特别要求的对角元分别是
> $$
> \frac{\partial y_i}{\partial z_j}
> =\frac{\gamma}{s}\left(\delta_{ij}-\frac1n-\frac{c_ic_j}{n(v+\epsilon)}\right),
> \qquad
> \frac{\partial y_i}{\partial z_i}
> =\frac{\gamma}{s}\left(1-\frac1n-\frac{c_i^2}{n(v+\epsilon)}\right).
> $$
> 批归一化使样本耦合，非对角导数通常非零；反传整个损失必须用全雅可比的转置作用于$u$，不能只逐个乘对角元。以下代码直接实现上面的逐节点算法：
>
> ```python
> """DS001 11.5: scalar batch normalization; no third-party dependency."""
> from math import sqrt
>
> def forward(z, gamma=1.0, delta=0.0, epsilon=1e-4):
>     if not z or epsilon <= 0:
>         raise ValueError("nonempty batch and positive epsilon required")
>     n = len(z)
>     mean = sum(z) / n
>     centered = [x - mean for x in z]
>     variance = sum(c*c for c in centered) / n
>     std = sqrt(variance + epsilon)
>     inv = 1.0 / std
>     normalized = [c * inv for c in centered]
>     y = [gamma*t + delta for t in normalized]
>     return y, (centered, std, inv, normalized, gamma)
>
> def backward(upstream, cache):
>     centered, std, inv, normalized, gamma = cache
>     n = len(centered)
>     if len(upstream) != n:
>         raise ValueError("gradient and batch shapes differ")
>     d7 = [gamma*u for u in upstream]
>     d2 = [a*inv for a in d7]
>     d6 = sum(a*c for a, c in zip(d7, centered))
>     d5 = -d6/(std*std)
>     d4 = d5/(2*std)
>     d3 = d4/n
>     d2 = [a + 2*c*d3 for a, c in zip(d2, centered)]
>     mean_d2 = sum(d2)/n
>     dz = [a - mean_d2 for a in d2]
>     dgamma = sum(u*t for u, t in zip(upstream, normalized))
>     ddelta = sum(upstream)
>     return dz, dgamma, ddelta
> ```
> 代码与有限差分核验入口保存在[[工具/UDL/examples/DL106-batchnorm.py|可运行的Python文件]]。已用Python 3.10.6（仅标准库math），从知识库根目录运行上述文件的核验入口。实际对$z=(-2,-0.4,0.3,1.7,2.2)$、$\gamma=1.3,\delta=-0.2,\epsilon=10^{-4}$、中心差分步长$10^{-5}$运行：25个雅可比元素最大绝对误差$2.68416\times10^{-11}$；取$u=(1,-2,0.4,0.1,0.7)$时反向输入梯度最大误差$1.94336\times10^{-11}$。这只核验该有限测试；解析公式由上述链式法则证明。
> 题中式(11.10)将$\epsilon$放在平方根内；正文式(11.8)则写在标准差外。这里严格按本题式(11.10)计算，两者的导数不能混用。
