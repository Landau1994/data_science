# 习题 DL109：标准残差序列与瓶颈块的参数比较

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 11.8** Consider a convolutional residual block that contains a batch normalization operation, followed by a ReLU activation function, and then a $3\times3$ convolutional layer. If the input and output both have 512 channels, how many parameters are needed to define this block? Now consider a bottleneck residual block that contains three batch normalization/ReLU/convolution sequences. The first uses a $1\times1$ convolution to reduce the number of channels from 512 to 128. The second uses a $3\times3$ convolution with the same number of input and output channels. The third uses a $1\times1$ convolution to increase the number of channels from 128 to 512 (see figure 11.7b). How many parameters are needed to define this block?

### 中文转述

> [!question] 中文转述
> 先计算一个BN→ReLU→$3\times3$卷积序列的参数，输入、输出均为512通道。再计算图11.7b的三序列瓶颈块：$1\times1$卷积512→128，$3\times3$卷积128→128，$1\times1$卷积128→512。计入BN可训练参数并明确卷积偏置约定。
>

## 提示

> [!hint]- 提示
> 卷积权重数为$k^2C_{\rm in}C_{\rm out}$；BN位于卷积之前，通道数取卷积输入宽度。

## 解答

> [!success]- 解答
> **独立推导。** 卷积每个输出通道共用一个偏置，BN每输入通道有$\gamma,\delta$两个参数，ReLU与恒等跳接均无参数。按题干的**一个**标准序列，
> $$
> P_{\rm one}=9(512)^2+512+2(512)=\boxed{2360832}.
> $$
> 瓶颈三层分别如下。
>
> |层|卷积权重|卷积偏置|前置BN|
> |---|---:|---:|---:|
> |$1\times1,\ 512\to128$|65536|128|1024|
> |$3\times3,\ 128\to128$|147456|128|256|
> |$1\times1,\ 128\to512$|65536|512|256|
> |合计|278528|768|1536|
>
> 所以瓶颈块共有$\boxed{280832}$个可训练参数，为上述单序列的约11.9%。输入输出同宽，恒等跳接无需投影参数。
> **计数约定。** 若去掉卷积偏置，两个答案分别为2360320和280064。图11.7a实际画的是两个标准BN/ReLU/卷积序列，若按整张图而非本题第一句的一个序列计数，则标准块为4721664（无卷积偏置时4720640）。BN的运行均值和方差是状态而不是训练参数，不计入上述数目。
