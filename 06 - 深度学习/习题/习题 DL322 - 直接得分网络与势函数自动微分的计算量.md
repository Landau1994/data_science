# 习题 DL322：直接得分网络与势函数自动微分的计算量

## 题目

### 英文原题

> [!question] 英文原题
> **20.15 (★★)** Consider a deep neural network representation $\mathbf s(\mathbf x,\mathbf w)$ for the score function defined by (20.42), where $\mathbf x$ and $\mathbf s$ have dimensionality $D$. Compare the computational complexity of evaluating the score for a network with $D$ outputs that represents the score function directly with one that computes a single scalar function $\phi(\mathbf x,\mathbf w)$ in which the score function is computed indirectly through automatic differentiation. Show that the latter approach is typically more computationally expensive.

### 中文转述

> [!question] 中文转述
> **原题20.15。** 考虑式(20.42)的 $D$ 维得分函数 $\mathbf s(\mathbf x,\mathbf w)$ 的深度网络表示。比较两种求值得分的计算复杂度：一是用 $D$ 个输出直接表示得分，二是先计算标量 $\phi(\mathbf x,\mathbf w)$，再用自动微分（automatic differentiation）间接计算得分。说明后一种方法通常需要更多计算。

## 提示

> [!hint]- 提示
> 标量对全部输入的梯度可用一次反向传播同时得到，不需要为每个输入单独运行一次。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** 设结构相近的网络一次前向计算代价为 $C$。直接得分网络在一次前向后已有全部 $D$ 个输出，求值成本约 $C_s$。势函数方案必须先前向得到标量 $\phi$，再反向传播求输入梯度 $\nabla_{\mathbf x}\phi$，因此成本约 $C_\phi+B_\phi$，其中反向代价通常与前向同量级，并需保存或重算中间状态。共享主干较大、输出层差异较小时，后一方案多出一次反向传播，通常更贵。
>
> 若还要训练得分匹配损失，直接方案对损失作一次参数反向传播；势函数方案需穿过已经构造的输入梯度计算图，再求参数导数，会涉及混合二阶导数及额外内存，因此正文的“两次反向”是该训练语境下的描述。
>
> 两种求值方案的渐近量级通常仍都是 $O(C)$，不能把一次反向误说成必然多一个 $D$ 因子。实际比例依赖架构、输出层大小、自动微分实现与硬件；原题的“typically”不是任意两网络的普适复杂度下界，本解答没有冒充实测计时。
