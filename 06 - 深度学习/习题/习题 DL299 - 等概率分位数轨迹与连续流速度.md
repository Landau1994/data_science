# 习题 DL299：等概率分位数轨迹与连续流速度

## 题目

### 英文原题

> [!question] 英文原题
> **Exercise 18.9（★★）** The flow lines in Figure 18.6 were plotted by taking a set of equally spaced values and using the inverse of the cumulative distribution function at each value of $t$ to plot the corresponding points in $z$-space. Show that this is equivalent to using the differential equation (18.27) to compute the flow lines where $\mathbf f$ is defined by (18.28).
>
> ![[附件/习题图/DS003/原图-18.6.png]]

### 中文转述

> [!question] 中文转述
> **原题18.9。** 图18.6的流线由一组等间距的累积概率值构造：在每个时刻 $t$，用逆累积分布函数求出各概率值对应的 $z$ 坐标并绘图。证明这等价于用微分方程(18.27)计算流线，其中 $f$ 由(18.28)定义。

## 提示

> [!hint]- 提示 1
> 固定 $u\in(0,1)$，令 $F(z(t),t)=u$ 并隐式求导。

> [!hint]- 提示 2
> 连续性方程加上左边界无通量，给 $\partial_tF=-qf$。

## 解答

> [!success]- 解答
> **独立推导及边界条件。** 设一维密度 $q(z,t)>0$、足够光滑，$F(z,t)=\int_{-\infty}^zq(s,t)\,\mathrm ds$。对固定概率 $u$，令 $z_u(t)=F_t^{-1}(u)$，则
> $$0=\frac{\mathrm d}{\mathrm dt}F(z_u(t),t)=\partial_tF(z_u,t)+q(z_u,t)z_u'(t).$$
> 因此分位数轨迹的速度为 $v(z,t)=-\partial_tF(z,t)/q(z,t)$。若密度由速度场 $f$ 输运，连续性方程为 $\partial_tq=-\partial_z(qf)$。加上 $qf\to0$（$z\to-\infty$），积分得 $\partial_tF=-qf$，于是 $z_u'=f(z_u,t)$，即(18.27)。
>
> 反过来，从分位数速度定义有 $\partial_tq=\partial_z\partial_tF=-\partial_z(qv)$，故沿轨迹
> $$\frac{\mathrm d}{\mathrm dt}\ln q(z_u(t),t)=\frac{\partial_tq+v\partial_zq}{q}=-\partial_zv,$$
> 正是(18.28)的一维形式。等间距的 $u$ 表示每两条流线之间质量相同；轨迹越密，密度越高。
>
> 单凭(18.28)是关于沿轨迹密度导数的方程，不能无条件唯一“定义” $f$；还要指定密度随时间的变化及边界通量。零密度区的逆CDF可不唯一，以上光滑论证只在正密度区域适用。
