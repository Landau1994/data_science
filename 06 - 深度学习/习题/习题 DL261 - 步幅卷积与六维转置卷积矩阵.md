# 习题 DL261：步幅卷积与六维转置卷积矩阵

## 题目

### 英文原题

> [!question] 英文原题
> **10.13 (★★)** In this exercise we use one-dimensional vectors to demonstrate why a convolutional up-sampling is sometimes called a transpose convolution. Consider a one-dimensional strided convolutional layer with an input having four units with activations $(x_1,x_2,x_3,x_4)$, which is padded with zeros to give $(0,x_1,x_2,x_3,x_4,0)$, and a filter with parameters $(w_1,w_2,w_3)$. Write down the one-dimensional activation vector of the output layer assuming a stride of 2. Express this output in the form of a matrix $\mathbf A$ multiplied by the vector $(0,x_1,x_2,x_3,x_4,0)$. Now consider an up-sampling convolution in which the input layer has activations $(z_1,z_2)$ with a filter having values $(w_1,w_2,w_3)$ and an output stride of 2. Write down the six-dimensional output vector assuming that overlapping filter values are summed and that the activation function is just the identity. Show that this can be expressed as a matrix multiplication using the transpose matrix $\mathbf A^{\mathsf T}$.

### 中文转述

> [!question] 中文转述
> 用一维向量说明卷积上采样何以称转置卷积（transpose convolution）。输入 $(x_1,x_2,x_3,x_4)$ 两侧填0为 $(0,x_1,x_2,x_3,x_4,0)$，核为 $(w_1,w_2,w_3)$、步长2。写出输出向量与矩阵 $A$。再对输入 $(z_1,z_2)$ 作输出步幅2的上采样卷积，重叠贡献求和，激活取恒等；写出六维输出并证明为 $A^{\mathsf T}z$。

## 提示

> [!hint]- 提示
> 正向矩阵两行分别在第1–3列和第3–5列放置核；第6列未被任何窗口读取。

## 解答

> [!success]- 解答
> **证明范围：独立推导。**
> 按书中互相关约定，从填充向量的0基位置0、2开始取宽3窗口，得到
> $$
> a=\binom{w_2x_1+w_3x_2}{w_1x_2+w_2x_3+w_3x_4},\qquad
> A=\begin{pmatrix}w_1&w_2&w_3&0&0&0\\0&0&w_1&w_2&w_3&0\end{pmatrix},
> $$
> 且 $a=A(0,x_1,x_2,x_3,x_4,0)^{\mathsf T}$。输出步幅2上采样时，第一个输入 $z_1$ 在输出位置0、1、2分别贡献 $w_1z_1,w_2z_1,w_3z_1$；第二个 $z_2$ 在位置2、3、4贡献 $w_1z_2,w_2z_2,w_3z_2$。重叠位置2相加，第6个位置5未收到贡献。因此
> $$
> u=\begin{pmatrix}w_1z_1\\w_2z_1\\w_3z_1+w_1z_2\\w_2z_2\\w_3z_2\\0\end{pmatrix}=A^{\mathsf T}\binom{z_1}{z_2}.
> $$
> 题目要求六维，故保留未被正向矩阵访问的最后一列所对应的尾部零。通常不指定该尾部尺寸的最短转置卷积输出长为 $(2-1)2+3=5$；六维是再保留一个零位置（输出形状约定），不是第六个可凭空学习的核贡献。
>
> 这是对填充输入空间上的线性算子取转置，满足 $\langle Av,z\rangle=\langle v,A^{\mathsf T}z\rangle$。若正向算子只定义在原四维输入上，设填充嵌入为 $P$，其矩阵是 $AP$，转置应为 $P^{\mathsf T}A^{\mathsf T}$，即再裁掉两侧填充坐标。转置一般不是逆；正向 $A$ 为 $2\times6$，降维且不可逆，所以上采样并不恢复被丢失的信息。
