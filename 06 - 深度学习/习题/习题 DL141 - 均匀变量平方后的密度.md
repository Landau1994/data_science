# 习题 DL141：均匀变量平方后的密度

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 16.1** Consider transforming a uniform base density defined on $z\in[0,1]$ using the function $x=f[z]=z^2$. Find an expression for the transformed distribution $Pr(x)$.

### 中文转述

> [!question] 中文转述
> 把 $[0,1]$ 上的均匀基分布经 $x=z^2$ 变换，求所得密度。


## 提示

> [!hint]- 提示
> 先求 $P(X\le x)$，或使用逆函数 $z=\sqrt x$。

## 解答

> [!success]- 解答
> 独立推导。当 $0\le x\le1$ 时，$F_X(x)=P(Z\le\sqrt x)=\sqrt x$；小于零时为零，大于一时为一。故几乎处处
> $$
> p_X(x)=\begin{cases}(2\sqrt x)^{-1},&0<x<1,\\0,&\text{其他}.
> \end{cases}
> $$
> 其积分为 $[\sqrt x]_0^1=1$。零点处导数发散，但 $P(X=0)=0$，没有额外点质量；密度单点取值不影响分布。
