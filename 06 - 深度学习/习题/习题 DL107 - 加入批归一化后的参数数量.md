# 习题 DL107：加入批归一化后的参数数量

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 11.6** Consider a fully connected neural network with one input, one output, and ten hidden layers, each of which contains twenty hidden units. How many parameters does this network have? How many parameters will it have if we place a batch normalization operation between each linear transformation and ReLU?

### 中文转述

> [!question] 中文转述
> 一个全连接网络有一个输入、一个输出和10个隐藏层，每层20个单元。先数可训练参数，再数每个隐藏层的线性变换与ReLU之间加入批归一化后的参数。

## 提示

> [!hint]- 提示
> 分别数首层、9个隐藏层之间的变换、输出层。每个BN通道多出缩放和偏移两个可训练标量。

## 解答

> [!success]- 解答
> **独立推导。** 保留每个仿射变换的偏置。首层$1\to20$有$20+20=40$个参数，9个$20\to20$变换各有$20^2+20=420$个，输出层$20\to1$有$20+1=21$个，因此
> $$
> P=40+9(420)+21=\boxed{3841}.
> $$
> 10个隐藏层的ReLU前各加入20通道BN；每通道有$\gamma,\delta$两个可训练参数，新增$10\times20\times2=400$个，得到
> $$
> P_{\rm BN}=\boxed{4241}.
> $$
> 批均值、批方差及推断时存储的运行统计不是额外可训练参数。若实现特意删除紧接BN的200个隐藏层仿射偏置，则得到4041；这是另一实现约定，题目没有要求删偏置。输出层后没有题设ReLU，故不额外添加输出BN。
