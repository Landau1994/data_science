# 习题 DL270：拼接位置编码经线性变换的可加分解

## 题目

### 英文原题

> [!question] 英文原题
> **12.9 (★★)** Consider a position encoding in which the input token vector $\mathbf x$ is concatenated with a position-encoding vector $\mathbf e$. Show that when this concatenated vector undergoes a general linear transformation by multiplication using a matrix, the result can be expressed as the sum of a linearly transformed input and a linearly transformed position vector.

### 中文转述

> [!question] 中文转述
> 将输入词元向量$\mathbf x$与位置向量$\mathbf e$拼接，再乘矩阵进行一般线性变换。证明结果可写成分别线性变换后的词元向量与位置向量之和。

## 提示

> [!hint]- 提示 1
> 按$x$和$e$的维度将变换矩阵分成两块。

## 解答

> [!success]- 解答
> **独立推导。**
>
> 以列向量为约定，设$x\in\mathbb R^D$、$e\in\mathbb R^P$，输出维度为$R$。任意$W\in\mathbb R^{R\times(D+P)}$都可唯一按列分块为$W=[W_x\ W_e]$，于是
> $$
> W\begin{pmatrix}x\\e\end{pmatrix}=W_xx+W_ee.
> $$
> 其中$W_xx,W_ee\in\mathbb R^R$，所以可以相加。采用行向量时，同一事实写成$[x^T\ e^T]\binom{U_x}{U_e}=x^TU_x+e^TU_e$。
>
> 这证明“先拼接再做任意线性变换”可以表示成“各自投影后相加”，但不意味着未经投影的原始向量直接相加总有相同表达能力；后者额外要求维度相同并对投影关系施加限制。
