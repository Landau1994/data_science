# 习题 DL267：自注意力的共享稀疏投影与动态混合矩阵

## 题目

### 英文原题

> [!question] 英文原题
> **12.6 (★★)** Express the self-attention function (12.14) as a fully connected network in the form of a matrix that maps the full input sequence of concatenated word vectors into an output vector of the same dimension. Note that such a matrix would have $O(N^2D^2)$ parameters. Show that the self-attention network corresponds to a sparse version of this matrix with parameter sharing. Draw a sketch showing the structure of this matrix, indicating which blocks of parameters are shared and which blocks have all elements equal to zero.

### 中文转述

> [!question] 中文转述
> 将自注意力函数(12.14)表示为矩阵形式的全连接网络，把拼接后的整个词向量序列映射为同维输出向量。一般这种矩阵具有$O(N^2D^2)$个参数。证明自注意力对应带参数共享的稀疏版本，并画矩阵结构草图，标明共享参数块及全零块。

## 提示

> [!hint]- 提示 1
> 将每个词视为列向量后堆叠。$Q,K,V$的投影逐词独立；注意力混合却依赖输入，不能视为固定权重。

## 解答

> [!success]- 解答
> **独立推导。**
>
> 取$D_v=D$以使输入输出同维，并按词堆叠列向量$x=(x_1^T,\ldots,x_N^T)^T$。一般固定全连接线性层为$y=Mx$，$M\in\mathbb R^{ND\times ND}$，共有$N^2D^2$个自由权重。
>
> 自注意力首先做逐词投影。沿用正文$V=XW^{(v)}$的行向量约定，堆叠列向量后就是
> $$
> v=(I_N\otimes W^{(v)T})x,
> $$
> 即所有对角块均为同一个$W^{(v)T}$，非对角块全零。$q,k$也分别由$I_N\otimes W^{(q)T}$、$I_N\otimes W^{(k)T}$得到；只需$DD_v+2DD_k$个投影权重，与$N$无关。
>
> 随后令$A(X)=\operatorname{Softmax}(QK^T/\sqrt{D_k})$，则
> $$
> y=(A(X)\otimes I_D)v,
> \qquad M(X)=A(X)\otimes W^{(v)T}=[a_{nm}(X)W^{(v)T}]_{n,m}.
> $$
> 因此每个有效块共享同一个值投影，只乘以由输入计算的标量。下图以$N=3$画出投影和混合两步：
>
> ![[附件/习题图/DS003/解答-12.6.png]]
>
> 上部的全零块与重复参数块严格说明稀疏性和共享；下部的$a_{nm}(X)$不是额外独立训练参数。有限未掩码Softmax的这些权重通常都为正，所以最终有效矩阵一般并不稀疏，且会随$X$变化。
>
> 由此需要限定题目的“稀疏版本”说法：它适用于各投影层的固定连接结构，不能把整个自注意力函数等同于一个固定稀疏全连接线性层。Softmax打分与激活间乘法使整体成为非线性函数。矩阵参数数目比较针对可学习投影，与仍需计算$N\times N$注意力权重的运算量不同。
