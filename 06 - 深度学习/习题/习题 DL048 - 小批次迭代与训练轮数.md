# 习题 DL048：小批次迭代与训练轮数

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 6.9** We run the stochastic gradient descent algorithm for 1,000 iterations on a dataset of size 100 with a batch size of 20. For how many epochs did we train the model?

### 中文转述

> [!question] 中文转述
> 数据100点、批大小20，SGD运行1000次更新，相当于多少训练轮（epochs）？



## 提示

> [!hint]- 提示
> 一轮使用100个样本，每步用20个。

## 解答

> [!success]- 解答
> **独立推导。** 按每轮无放回完整遍历的约定，每轮 $100/20=5$ 次更新，故共 $1000/5=200$ 轮。也可计算累计处理 $20000$ 个样本再除以100。若批次有放回抽样，只能称200个等效遍历量，不保证每个样本恰好见到200次。
