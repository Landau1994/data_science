# 习题 DL093：混合步幅与膨胀下的逐层感受野

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 10.11** Consider a convolutional network with 1D input $\mathbf x$. The first hidden layer $\mathbf H_1$ is computed using a convolution with kernel size five, stride two, and a dilation rate of one. The second hidden layer $\mathbf H_2$ is computed using a convolution with kernel size three, stride one, and a dilation rate of one. The third hidden layer $\mathbf H_3$ is computed using a convolution with kernel size five, stride one, and a dilation rate of two. What are the receptive field sizes at each hidden layer?

### 中文转述

> [!question] 中文转述
> 一维输入依次通过$(k,s,d)=(5,2,1),(3,1,1),(5,1,2)$三个卷积层。求每个隐藏层在原输入上的感受野大小。

## 提示

> [!hint]- 提示
> 前层步幅使后续核的相邻采样位置在原输入上间隔更大；用前一层的$j$扩展跨度。

## 解答

> [!success]- 解答
> **独立推导。** 令$r_\ell$为第$\ell$层单元在原输入上的理论覆盖跨度，$j_\ell$为相邻单元中心在原输入上的间隔。初始$r_0=j_0=1$；核大小$k_\ell$、步幅$s_\ell$、膨胀率$d_\ell$给出
> $$
> r_\ell=r_{\ell-1}+(k_\ell-1)d_\ell j_{\ell-1},\qquad
> j_\ell=s_\ell j_{\ell-1}.
> $$
>
> 逐层代入得到：
>
> |层|$k,s,d$|$j_{\ell-1}$|$r_\ell$|$j_\ell$|
> |---|---|---:|---:|---:|
> |$H_1$|$5,2,1$|1|$1+4=5$|2|
> |$H_2$|$3,1,1$|2|$5+2(2)=9$|2|
> |$H_3$|$5,1,2$|2|$9+4(2)(2)=25$|2|
>
> 答案依次为$\boxed{5,9,25}$。第三层虽然膨胀采样，但每个被采样的第二层单元已覆盖9个连续输入位置，五段的中心间隔为4，彼此重叠，故其并集仍为连续25格。该数是理论跨度；有限输入边缘需扣除补零，特殊权重抵消可能降低实际函数依赖。
