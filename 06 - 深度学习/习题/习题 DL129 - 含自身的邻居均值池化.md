# 习题 DL129：含自身的邻居均值池化

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 13.9** The authors of GraphSAGE (Hamilton et al., 2017a) propose a pooling method in which the node embedding is averaged together with its neighbors so that:
> $$
> \operatorname{agg}[n]=\frac1{1+|\operatorname{ne}[n]|}
> \left(\mathbf h_n+\sum_{m\in\operatorname{ne}[n]}\mathbf h_m\right).\tag{13.30}
> $$
> Show how this operation can be computed simultaneously for all node embeddings in the $D\times N$ embedding matrix $\mathbf H$ using linear algebra. You will need to use both the adjacency matrix $\mathbf A$ and the degree matrix $\mathbf D$.

### 中文转述

> [!question] 中文转述
> **UDL 原题 13.9。** GraphSAGE提出式(13.30)：将节点自身与全部邻居的嵌入作平均。用邻接矩阵 $A$、度矩阵 $D$ 和按列存储嵌入的 $D_{\rm emb}\times N$ 矩阵 $H$，写出同时计算所有节点结果的矩阵式。

## 提示

> [!hint]- 提示
> 先用 $H(A+I)$ 求含自身的和，再从右侧按每列的邻居数量归一化。

## 解答

> [!success]- 解答
> **独立推导。** 这里 $D$ 专指度矩阵，嵌入维数另记为 $D_{\rm emb}$。对无向无自环图，$H(A+I)$ 的第 $n$ 列恰为 $h_n+\sum_{m\in\operatorname{ne}[n]}h_m$。因此
> $$
> \operatorname{Agg}(H,A)=H(A+I)(D+I)^{-1}.
> $$
> 最右对角矩阵的第 $n$ 个元素是 $1/(d_n+1)$，故逐列得到原式。即使节点孤立，$d_n+1=1$，结果仍定义良好且等于其自身嵌入。不能把右归一化直接移到左边，因为 $H$ 的行是特征、列才是节点；对有向图则须先固定 $A_{mn}$ 所表示的信息流方向，并用相应列和。
