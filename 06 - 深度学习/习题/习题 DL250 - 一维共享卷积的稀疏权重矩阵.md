# 习题 DL250：一维共享卷积的稀疏权重矩阵

## 题目

### 英文原题

> [!question] 英文原题
> **10.2 (★★)** Consider a convolutional network layer with a one-dimensional input array and a one-dimensional feature map as shown in Figure 10.2, in which the input array has dimensionality 5 and the filters have width 3 with a stride of 1. Show that this can be expressed as a special case of a fully connected layer by writing down the weight matrix in which missing connections are replaced by zeros and where shared parameters are indicated by using replicated entries. Ignore any bias parameters.

### 中文转述

> [!question] 中文转述
> 考虑图10.2式的一维输入与一维特征图；本题指定输入长5、滤波器宽3、步长1。忽略偏置，写出稀疏权重矩阵：缺失连接填0，共享参数用重复元素表示，从而将此卷积层写为全连接层的特例。

## 提示

> [!hint]- 提示
> 无填充时有3个有效窗口；每一行的三个滤波器参数相对前一行右移一格。

## 解答

> [!success]- 解答
> **证明范围：独立推导。**
> 按题给输入 $x=(x_1,\ldots,x_5)^{\mathsf T}$，卷积核 $(k_1,k_2,k_3)$，采用书中的互相关约定、无填充。三个预激活为 $a_j=k_1x_j+k_2x_{j+1}+k_3x_{j+2}$、$j=1,2,3$，所以
> $$
> a=Wx,\qquad W=\begin{pmatrix}
> k_1&k_2&k_3&0&0\\
> 0&k_1&k_2&k_3&0\\
> 0&0&k_1&k_2&k_3
> \end{pmatrix}.
> $$
> 若有逐坐标激活，输出为 $h(Wx)$。这个 $3\times5$ 全连接矩阵受两个约束：六个位置固定为0，其余九个位置由三个共享参数决定。故有9条非零模式连接但仅3个独立可学习参数。
>
> 原图10.2实际画的是4输入、宽2、3输出的例子，与题面5输入、宽3不同；其矩阵对应 $\bigl[\begin{smallmatrix}k_1&k_2&0&0\\0&k_1&k_2&0\\0&0&k_1&k_2\end{smallmatrix}\bigr]$。两者展示同一稀疏共享结构，题目数值解以文字指定为准。
>
