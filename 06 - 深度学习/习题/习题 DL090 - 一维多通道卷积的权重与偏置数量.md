# 习题 DL090：一维多通道卷积的权重与偏置数量

## 题目

### 英文原题

> [!question] 英文原题
> **Problem 10.8** Consider a 1D convolutional network where the input has three channels. The first hidden layer is computed using a kernel size of three and has four channels. The second hidden layer is computed using a kernel size of five and has ten channels. How many biases and how many weights are needed for each of these two convolutional layers?

### 中文转述

> [!question] 中文转述
> 输入3通道；第一层核大小3、输出4通道；第二层核大小5、输出10通道。分别求两层权重数和偏置数。

## 提示

> [!hint]- 提示
> 每个输出通道对全部输入通道各放一个核，但只配一个共享空间偏置。

## 解答

> [!success]- 解答
> **独立推导。** 普通、非分组的一维卷积有$KC_{\rm in}C_{\rm out}$个权重，每输出通道一个偏置，共$C_{\rm out}$个。
> 第一层$K=3,C_{\rm in}=3,C_{\rm out}=4$：$\boxed{36\text{个权重，}4\text{个偏置}}$，合计40。
> 第二层输入通道数是前层输出的4，故$K=5,C_{\rm in}=4,C_{\rm out}=10$：$\boxed{200\text{个权重，}10\text{个偏置}}$，合计210。
> 空间上反复使用同一组核与偏置，因此参数数目不乘输入长度或输出位置数；步幅、填充、膨胀也不改变这些核参数的数量。
