## 保留的原文疑误与表述边界

以下均是源页中的内容，译文原样保留，没有静默修正. 它们是原文的疑误或省略边界，不是本译文新增的数学结论.

1. 印刷39 / 物理53：对所有`Q∈Q`后又写`j=1,…,2^d`，但j没有出现在该条件内. 译文保留这个冗余指标.
2. 印刷41–42 / 物理55–56：构造先仅对1≤j<J定义μ'_j，随后式(2.5)包含j=J. 若J=0，初始μ_J与最后μ_0定义也须另作平凡情形处理. 归一化分母为零的情况只对μ_J明确约定，递归步与ν_J需同类约定；译文未补写约定.
3. 印刷42 / 物理56：引理2.4设置μ'_0=μ_0；其后“第二个等号由定义”在j=0时，与该式及原递归定义存在衔接问题. 译文保留μ'_0=μ_0及完整原推导，没有私自改写递归.
4. 印刷45 / 物理59：网格指标记`[2^j−1]:={0,…,2^j−1}`，与常见[n]记号以及前文习惯不同. 译文保留这一显式定义. 末段把被覆盖函数类重新写作F，亦保留原泛称.
5. 印刷47 / 物理61：链式证明取τ=4√d n^(−1/d)，当n很小时可能大于积分上限√d；该速率论证应按渐近范围解释，或另用平凡界处理小样本，原文未说明.
6. 印刷48 / 物理62：d_{T^d}在R^d上被称为度量；它在相差2π整数向量的点之间为零，严格说在R^d上是伪度量，在商环面上才是度量. 译文保留原称法，环面解释也完整保留.
7. 印刷52 / 物理66：定理2.13的最后和式被称为对所有ε>0具有log(1/ε)的阶，实际使用是ε趋于0/大样本时的比较；n=1等小样本需另行解释. 译文未更换log或增加样本下界.
8. 印刷54 / 物理68：阈值T_n^α被要求使原假设下尾概率恰为α；对存在原子的统计量，一般不能保证任意α都精确达到，需广义分位数或随机化约定. 译文保留原等号与严格尾事件.
9. 印刷56–58 / 物理70–72：下界证明直接把单位立方体划成恰好2n个等边长立方体，边长(2n)^(−1/d)，一般n未必允许这种整齐网格划分. 原页没有取整或替代铺排处理；译文未改构造或常数.
10. 印刷56 / 物理70：先定义最近点为ξ(x)，随后公式写ξ_n(x)；又在fn(x_i)=0之后写∫f dμ̃_n=0，未带n下标. 译文分别保留原记号.
11. 印刷60 / 物理74：导数Fourier展开写m^(2α)φ_μ(m)，而通常导数阶对应m^α及虚数因子；下一行Parseval平方表达式又采用m^(2α). 译文保留原导数展开，未将其暗改为正确公式.
12. 印刷60–61 / 物理74–75：声称由二项式定理有||m||^(2s)=Σ_{|α|=s}m^(2α)，缺少多项式系数；后续(2.17)也使用这个等号. 范数等价可通过适当比较处理，但译文没有重证明或改等号.
13. 印刷62 / 物理76：定理2.18的陈述没有明确保留命题2.17的d≥3条件，证明直接调用该命题；低维速率须另行处理. 译文保持原定理陈述的范围，不把它扩充为已核验的低维结论.
14. 印刷64–65 / 物理78–79：RKHS起初假定核有界，随后线性核例子在R^d上并不有界. 此外，F_lin用||θ||=1定义，而后把它称为RKHS单位球（通常应是≤1）. 译文完整保留例子、球面约束与后文的“单位球”称谓.
15. 印刷66–67 / 物理80–81：MMD经验估计段把Y_1,…,Y_n的来源同样写成μ，随后仍使用ν_n及MMD(μ,ν). 译文保留Y来自μ的原句；通常这里预期为ν.
16. 印刷71 / 物理85：讨论将p>1的Wasserstein收敛概括为所有高阶矩收敛并援引命题1.5，后者有次指数尾条件；不能脱离该尾条件把此概括视为一般定理. 译文保留原讨论，未扩充假设.
17. 印刷74 / 物理88：习题1(c)把耦合集记成Γ(μ,μ̃_n)，不同于正文Γ_{μ,ν}；译文保留原括号写法.
18. 印刷75 / 物理89：习题7(b)用KL(μ^(1),μ^(0))的逗号记号，不同于前段竖线记号；译文保留. 习题9的MSW定义在最大值下标写θ∈S，而此前只定义S^(d−1)，未定义单独S；译文保留S，后续分题仍保留原S^(d−1).
