# 全书引用与链接映射

更新日期：2026-11-03. 当前范围为全书，原第1章试译中跨原PDF的externalref只是历史做法；完整译稿已全部改为译稿内部实际对象，不残留原书跨文件占位链接.

## 映射约定

| 原文目标 | 译稿稳定标签 | 显示/跳转 |
| --- | --- | --- |
| 章、附录 | sec:1..8、sec:A、sec:B | 中文autoref及实际章节目标 |
| 节、次节 | sec:章.节[.次节] | 中文autoref，保留原层级 |
| 定理、引理、命题、推论 | thm、lem、prop、cor:原号 | 原类别与共享原编号 |
| 定义、例、假设、注 | def、ex、assump、rem:原号 | 原类别；不将所有对象泛称定理 |
| 数字公式 | eq:章.序号 | eqref显示原括号编号 |
| 命名公式 | eq:KOT、eq:W22、eq:D-W22、eq:SD等 | 原tag；第2章eq:2.Aj单列 |
| 图 | fig:章.序号；前言独立图1 | 原图号及实际图位置 |
| 习题 | exer:章.题号 | 各章显示1..N；原明确章号保留 |
| 条件、列表分项 | item等独立label | 实际条目锚点，不伪造公式号 |
| 文献 | ref1..ref330 | cite指向书目，显示原数字1..330 |
| 索引 | 正文index与see | 译稿真实页码，100逻辑词条/104写入 |

原文自身错引另见各章review. 如将命题7.5称“定义7.5”，译文保留可见原称且链接到真实prop:7.5，并在源问题记录说明；不为消除源错而虚构对象.
