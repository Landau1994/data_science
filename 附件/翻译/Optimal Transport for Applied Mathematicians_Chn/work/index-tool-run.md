# 技能索引工具的隔离执行

已读原脚本接口：没有CLI参数，主入口硬编码另一教材的输入输出路径. 本轮通过runpy加载并实际调用其parse_original_terms_cleaned与insert_index_anchors函数. 输入为按原索引逐条核对后的英文索引Markdown，输出限定于work/index-tool-sandbox/tex的正式正文副本；正式正文没有传给该插入函数.

解析结果160项；详细运行输出见index-tool-safe-run.log. 脚本的通用数字／关键词清理会对数学词条产生误拆，模糊英文匹配也不能代表中文译稿的语义位置，故所有副本落点都不用于正式索引. 正式索引只由完整index-map.json中的356个已核对目标精确生成.

调用前后对全部正式正文文件作SHA256比对，工具执行期间正式正文完全未变. 隔离副本仅用于工具机制验证，不纳入主稿.
