# 全书引用方案与实际定位

数字陈述obj:N.M；知识框box:N.M；数字公式eq:N.M；节sec:N[.M[.K]]；图fig:N.M；习题ex:1–69；原提示hint:1–69；书目b1–b300。所有可点击原文引用使用autoref、eqref、hyperref或原外部网址。前置与第1章原有153处orig均已内部化，109行完整原目录仍显示原页码，并跳到对应译文单元；44处其他可见文字保持不变。完整转换清单见reference-internalization-records.json。

原文错误引用保持原可见编号并指向其真实编号对象，不把推测的正确对象偷换进去，例如定义1.12仍显示(3.1)。原文引用的对象种类错误（例如称命题为引理）同样单独记录，不创造假对象。文献以bN稳定键与plain排序字段保留原1–300编号。

索引映射详见index-map.json，每个出处保存原印刷页／物理页、语义目标与核对依据；不造新出处。原351个页码提及中的3个范围展开为356个出处；相同译文页号可由makeindex合并。每一实际锚点均对应正文真实语义位置，禁止用普通词语或装饰性链接弥补缺失引用。

最终将按源页单元比较实际PDF内部链接与译文内部链接，结合aux及命令逐项核查；总数不代替章节和可见引用对照。实际审计输出见full-audit.json及pdf-link-audit-report.md。未实测Obsidian界面，也不把结构目的地解析称为逐个交互点击。
