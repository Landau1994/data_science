# PDF实际链接审计

范围比较限定于本批来源：原PDF物理1–85及362–373；不以376页全书总链接数要求94页分批译稿。

- 来源选定范围：406个内部链接、29个网页链接。
- 最终译稿：312个GoTo内部链接、157个GoToR原书链接、31个URI链接，合计500个注释；519个实际命名目的地。
- 原第1章：209个内部链接；译稿第1章：201个内部链接加15个原书链接，共216个相关注释。原书未译章节和习题的引用在译稿中转为外部原书跳转，不能只比较GoTo一种类型。
- 全部内部名称目标存在；全部GoToR文件路径从正式PDF所在目录解析存在，物理页目标均在原件376页范围内；300个文献编号与实际bibcite映射一致。

已通过实际PDF结构审计，而非只搜TeX命令。不同排版可把一处文字引用拆成多个注释，因此总数仅为信号；来源逐段核对和reference-map用于确认语义目标。未在Obsidian或外部PDF阅读器中逐个点击测试。
