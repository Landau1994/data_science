Poisson Distribution

The Poisson distribution is a widely applied discrete distribution, and can serve as a model for a
number of different types of experiments. For example, if we are modeling a phenomenon in which
we are waiting for an occurrence (such as waiting for a bus, waiting for customers to arrive in a
bank), the number of occurrences in a given time interval can sometimes be modeled by the Poisson
distribution. One of the basic assumptions on which the Poisson distribution is built is that, for
small time intervals, the probability of an arrival is proportional to the length of waiting time. This
makes it a reasonable model for situations like those indicated above. For example, it makes sense
to assume that the longer we wait, the more likely it is that a customer will enter the bank. See the
Miscellanea section for a more formal treatment of this.
   Another area of application is in spatial distributions, where, for example, the Poisson distribu-
tion may be used to model the distribution of bomb hits in an area or the distribution of fish in a
lake.
   The Poisson distribution has a single parameter λ, sometimes called the intensity parameter. A
random variable X, taking values in the nonnegative integers, has a Poisson(λ) distribution if
