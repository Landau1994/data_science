Theorem 3.5.6   Let f(·) be any pdf. Let µ be any real number and let σ be any positive real
number. Then X is a random variable with pdf (1/σ) f((x−µ)/σ) if and only if there exists arandom variable Z with pdf f(z) and X = σZ + µ.
