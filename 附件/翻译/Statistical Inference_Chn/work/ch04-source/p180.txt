   Given that Xn = xn, there must have been m −xn trials that resulted in one of the first n −1
outcomes. The vector (X1,...,Xn−1) counts the number of these m−xn trials that are of each type.
Thus, it seems that given Xn = xn, (X1,...,Xn−1) might have a multinomial distribution. This is true.

This is the pmf of a multinomial distribution with m −xn trials and cell probabilities p1/(1 −
pn),..., pn−1/(1 −pn). In fact, the conditional distribution of any subset of the coordinates of(X1,...,Xn) given the values of the rest of the coordinates is a multinomial distribution.
  We see from the conditional distributions that the coordinates of the vector (X1, ..., Xn) are
related. In particular, for a fixed m, as there must be some negative correlation. In fact, all of the
pairwise covariances are negative, and are given by (Exercise 4.39):

                      Cov(Xi,Xj) = E[(Xi −pi)(Xj −pj)] = −mpipj.
Thus, the negative correlation is bigger for variables with higher success probabilities. This makes
sense, as the variable total is constrained at m, so if one starts to get big, the other tends not to.
