An LRT is a test that rejects H0 for small values of λ(x). Using (8.2.2), the rejection region, {x:
λ(x) ≤c}, can be written as
                             {x: |x−θ0| ≥   −2(logc)/n}.
As c ranges between 0 and 1,   −2(logc)/n ranges between 0 and ∞. Thus the LRTs are just thosetests that reject H0 : θ = θ0 if the sample mean differs from the hypothesized value θ0 by more than
