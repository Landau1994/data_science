Example 8.3.3 (Normal power function)   Let X1,...,Xn be a random sample from a n(θ,σ2)
population, σ2 known. An LRT of H0 : θ ≤θ0 versus H1 : θ > θ0 is a test that rejects H0 if (X −θ0)/(σ/√n) > c (Exercise 8.37). The constant c can be any positive number. The power function
of this test is

    Typically, the power function of a test will depend on the sample size n. If n can be chosen by
the experimenter, consideration of the power function might help determine what sample size is
appropriate in an experiment.
