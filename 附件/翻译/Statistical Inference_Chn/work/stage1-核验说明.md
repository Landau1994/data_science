## 原文疑误与边界

以下均为原文实际内容，译文照录；本说明的核对意见与作者原文分开。翻译完成不表示这些断言数学上正确。

| 原位置（印刷／PDF物理页） | 保留内容与核对意见 |
| --- | --- |
| 版权页，未印页码／5 | 编目写Roger W.，扉页与版权正文写Roger L.；不静默统一编目原文。 |
| 第二版前言，xi／12 | 计算与模拟指向§5.5，虽然新目录的生成样本在§5.6；原指向保留。 |
| 第一版前言，xiii–xv／14–16 | 全部旧章节安排照录，不能按第二版目录改写；未给旧版不存在于本文件中的目标伪造当前章节链接。 |
| 图目录，xxi／22 | 图2.1.2标题原印“increasing and nonincreasing cdfs”，照译“递增与非递增的累积分布函数”。 |
| 例目录，xxiv／25 | 2.4.9原称“习题2.4.7续”，保留“习题”。 |
| 图1.2.2，16／47 | 图注总体为$\{2,4,4,9\}$，正文为$\{2,4,9,12\}$，二者不一致；直方图也对应正文总体。 |
| 例1.2.20，16／47 | 原式$9/128=.07$保留，精确值为$0.0703125$；原文使用近似值却写等号。 |

| 例1.4.3，23／54 | 原表在$X=1$行重复列出HTH、THH，与$X$表示正面次数不符；表格原样保留。 |
| §1.6末段，31／62 | 作者说明连续分布不必有密度，并把讨论限制到满足积分关系的情形；这段限制完整保留。 |
