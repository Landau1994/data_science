    Finally, it was mentioned earlier that, since MLEs are found by a maximization process, they are
susceptible to the problems associated with that process, among them that of numerical instability.
We now look at this problem in more detail.
    Recall that the likelihood function is a function of the parameter, θ, with the data, x, held con-
stant. However, since the data are measured with error, we might ask how small changes in the data
might affect the MLE. That is, we calculate ˆθ based on L(θ|x), but we might inquire what value we
would get for the MLE if we based our calculations on L(θ|x+ε), for small ε. Intuitively, this newMLE, say ˆθ1, should be close to ˆθ if ε is small. But this is not always the case.
