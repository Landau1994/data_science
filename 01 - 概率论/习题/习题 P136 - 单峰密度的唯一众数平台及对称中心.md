# 习题 P136：单峰密度的唯一众数平台及对称中心

## 题目

### 英文原题

> [!question] 英文原题
> **2.27** Let $f(x)$ be a pdf and let $a$ be a number such that, if $a\ge x\ge y$ then $f(a)\ge f(x)\ge f(y)$ and, if $a\le x\le y$ then $f(a)\ge f(x)\ge f(y)$. Such a pdf is called unimodal with a mode equal to $a$.
>
> (a) Give an example of a unimodal pdf for which the mode is unique.
>
> (b) Give an example of a unimodal pdf for which the mode is not unique.
>
> (c) Show that if $f(x)$ is both symmetric (see Exercise 2.26) and unimodal, then the point of symmetry is a mode.
>
> (d) Consider the pdf $f(x)=e^{-x}$, $x\ge0$. Show that this pdf is unimodal. What is its mode?

### 中文转述

> [!question] 中文转述
> **原题2.27。** 设 $f(x)$ 为概率密度函数，$a$ 为一个数，使得当 $a\ge x\ge y$ 时，$f(a)\ge f(x)\ge f(y)$；当 $a\le x\le y$ 时，也有 $f(a)\ge f(x)\ge f(y)$. 称这样的密度为单峰（unimodal）密度，$a$ 为一个众数（mode）.
>
> (a)  举出一个众数唯一的单峰密度.
>
> (b)  举出一个众数不唯一的单峰密度.
>
> (c)  证明，如果 $f(x)$ 既对称（见习题2.26）又单峰，则其对称中心是一个众数.
>
> (d)  考虑密度 $f(x)=e^{-x}$，$x\ge0$. 证明该密度单峰. 它的众数是什么？

## 提示

> [!hint]- 提示
> 用正态与均匀密度区分尖峰与平台；对(c)把原众数反射到对称中心另一侧。

## 解答

> [!success]- 解答
> **证明范围：独立推导。** **(a)** 标准正态$\phi(x)$在负半轴严格增加、正半轴严格减少，唯一众数0。
>
> **(b)** 取$f(x)=\frac12$于$[-1,1]$，支持外0。任意$a\in[-1,1]$都满足原题两侧非严格单调条件，因此众数不是唯一。
>
> **(c)** 设对称中心为$c$，已知某众数为$a$，其高度为全局最大值$f(a)$。对称性给$f(2c-a)=f(a)$。若$a\le c$，则沿众数右侧的非增性给$f(a)\ge f(c)\ge f(2c-a)=f(a)$，所以$f(c)=f(a)$。若$a\ge c$，沿众数左侧同理论证。故$c$也是众数。
>
> **(d)** 把原密度在负半轴补0、并依原文取$f(0)=1$。当$0\ge x\ge y$时，若$x<0$则两处密度均0，若$x=0$则$f(x)=1\ge f(y)$；当$0\le x\le y$时，$1\ge e^{-x}\ge e^{-y}$。所以它单峰且唯一众数为0。
>
> 众数是题目给定密度版本的逐点概念；若仅在零测集上任意修改密度高度，分布不变，但这种点态众数表述可能改变。此处始终沿用指定版本。
