# 来源台账（Source Registry）

用于登记真实的教材、论文、课程与数据集，并区分“已登记”“已核对原文”和“已归档习题”。

## 编号约定

- 本库使用独立来源编号，按登记顺序采用 `DS001`、`DS002` 等；编号分配后不重排。
- 创建 [[模板/来源笔记模板|来源笔记]]，记录作者、完整标题、版本、文件位置或网址，以及核对范围。
- 精确引文记录章节、结果或题号，并同时记录印刷页与 PDF 物理页；网页材料记录稳定链接及访问日期。
- OCR 只作检索辅助。公式、分题、图示和精确页码应与原始材料核对。

## 已登记来源

```dataview
TABLE WITHOUT ID source_id AS "编号", file.link AS "来源", source_kind AS "类型", source_status AS "核对状态"
FROM #source
WHERE source_id
SORT source_id ASC
```

## 教材归档进度

```dataview
TABLE WITHOUT ID source_id AS "来源编号", file.link AS "教材记录", archived_chapters AS "已归档章节", archived_exercise_count AS "已归档题数", archive_status AS "全书归档状态"
FROM #source
WHERE archive_status
SORT file.name ASC
```

教材与配套资料统一保存在“教材归档”目录，一份材料对应一篇统一台账。阅读进度、章节审计、题目映射和对账结果均并入对应教材记录，不另建独立学习台账或章节台账文件。
