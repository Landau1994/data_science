# UDL 台账与手动预览工具

这是本知识库独立的UDL归档对账与手动预览工具，当前来源清单覆盖第1–21章全部197道章末编号习题，第1、14章已逐页核对为零题。它读取习题笔记中的实际学习状态，以原始题号顺序生成预览；不维护随机抽样、间隔复习或出题队列，也没有定时任务。

统一入口：[[00 - 首页/教材归档/DS001 - Understanding Deep Learning|UDL 学习与归档台账]]。教材记录保留 21 章阅读表及一份 [[00 - 首页/教材归档/DS001 - Understanding Deep Learning#习题归档|动态习题表]]；原题核对依据、页码及映射由下方来源清单与习题自身的来源字段保存，台账不重复列出处理过程。

## 来源清单

`source-manifest.json` 保存本地UDL PDF的SHA-256、逐章有序题号、星号、实际页码、图示依赖和一题一笔记映射。全书197题，其中本轮第5–21章新增165题（DL030–DL194）；已有ML001–ML003、DL001–DL029保留。每题包含可检索的完整英文原题、中文转述、提示与解答，学习进度仍读取Markdown属性。

空题号集合只用于已经人工核对为零题的章节，不表示未审核或漏归档。第1章末的Notebook1.1不是编号习题，不创建占位笔记；第1、14章均不能生成非空习题预览。

新增章节时，先对照原始习题页核对有序题号、总数、跨页内容与图示，完成一题一笔记后再扩展清单。未审核的章节不会被工具虚构为已入库。

## 手动运行

从知识库根目录运行，使用 Python 3.10 或更新版本；只依赖标准库：

```powershell
python -X utf8 工具/UDL/udl_manager.py audit --chapter 1
python -X utf8 工具/UDL/udl_manager.py audit --chapter 2
python -X utf8 工具/UDL/udl_manager.py audit --chapter 3
python -X utf8 工具/UDL/udl_manager.py audit --chapter 21
python -X utf8 工具/UDL/udl_manager.py preview --chapter 2 --count 3 --date 2026-10-24
```

本机已用 Codex 随附 Python 实际运行。若系统命令 `python` 不可用，可使用本机现有 Python 程序路径；无需安装第三方库。

`audit` 只读核对来源文件摘要、有序题号与笔记映射，并报告预期数、实际数、缺失、重复、多余、无法解析及字段问题；失败时返回非零退出码。

`preview` 先进行对账，仅在通过后写入 `12 - 每日题单/UDL 试运行 - 日期.md`。同一日期重跑时，只替换 `UDL-PREVIEW` 受管理区块，保留区块外的作答与备注；标记缺失或不唯一时拒绝覆盖。它不会修改习题的 `status`。

## 当前边界

- 归档完成与个人学习完成分别记录。本轮没有生成新题单；下方preview功能仍需用户手动调用。
- 台账、提示和解答为中文，题目同时保留经原页核对的英文原题与中文转述；保留英文章名、原题号、星号及来源位置。对账会检查双语题目结构，逐字准确性仍由原页核对负责。
- 用户确认持有英文纸书，具体纸书印次与页码尚未逐项对齐；目前按附件英文 PDF 核对。
- 这里只为已人工核对的题号运行结构对账；通过对账不表示程序能够审核题意、证明或答案正确性。
- 暂未接入 Obsidian 按钮、共享 Exercise Manager、历史抽样状态或定时自动出题。

## 本轮有限计算与绘图

`experiments/`保存实际使用的习题计算或绘图代码；输入、环境、随机种子及结果见对应习题与附件。它们是有限范围的习题核验，不代表用户运行过实验或学习已完成，也不构成对训练结果的普遍保证。图网络的整数核验与四张TikZ解答图由`experiments/ch13_graphs.py`重建，需本机TeX Live与Poppler。
