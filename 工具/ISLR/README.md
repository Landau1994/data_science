## 运行方法

需要 R 可以载入相应包；脚本不自动安装依赖。第 6.8 题需要 `leaps`、`glmnet`，另两题需要 `ISLR2`、`glmnet`、`pls`。在 WSL 终端中，例如：

```sh
Rscript /mnt/e/project/math/data_science/工具/ISLR/islr_ch6_applied.R 6.8 /path/to/new-output-directory
```

将题号换成 `6.9` 或 `6.11` 可运行另两题；将示例输出位置替换成自己的项目存储目录。目录必须不存在或为空，脚本不会覆盖既有运行结果。若另有任务 R 库，用 `R_LIBS=/path/to/library Rscript ...` 附加；不要替换原个人库而丢失既有依赖。

随机生成器为 Mersenne-Twister、Inversion、Rejection，种子 20261025。6.8 使用固定五折；6.9 与 6.11 先随机留出约 30% 行作测试集，再在训练资料内固定五折。调参网格为 $10^5$ 至 $10^{-4}$ 的 100 个对数等距点；训练折内估计缩放与成分方向，测试集不参与选择。种子固定不保证跨平台逐位一致。
