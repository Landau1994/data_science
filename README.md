# 数据科学知识库（Data Science）

以**概率论 → 数理统计 → 统计学习／概率推断 → AI**为主线的中文 Obsidian 知识库，同时整理线性代数、优化、因果推断、时序与可复现计算。

## 开始使用

1. 在 Obsidian 中“打开文件夹作为仓库”，选择 `E:\project\math\data_science`。
2. 打开 [[00 - 首页/索引|首页索引]] 与 [[00 - 首页/使用指南|使用指南]]。
3. 打开 [[00 - 首页/建设计划|建设计划与验收清单]]，查看本轮完成项与后续顺序。
4. 从主题导航进入概念、习题和来源，使用 Templater 插入“模板”目录中的模板。

正文与标题为中文；关键概念首次出现标明英文，概念笔记保留英文别名。概念的 `source` 属性直接写教材名、章节和印刷页／PDF物理页，使用普通文字；正文保留来源台账链接及核对边界。用于追踪的字段与枚举保持稳定英文值。

## 内容与来源边界

概念、习题和来源记录从 [[00 - 首页/索引|首页追踪入口]] 动态查看；来源包括附件教材及官方文章／原始论文，各概念按实际核对范围记录定位。“可复现分析”是有参考来源的本库独立约定，仍保持 `unverified`。UDL全书197题通过Dataview动态列出，相关习题由概念的动态查询回查；第2章的图示见 [[知识图谱/UDL第2章概念与习题.canvas|概念与习题双向图]]。尚未建立独立项目或实验笔记；习题内的有限计算、合成训练与绘图已保留实际代码和结果。

基础入口见 [[06 - 深度学习/概念/神经网络|神经网络]]；UDL台账按章节组织 [[00 - 首页/教材归档/DS001 - Understanding Deep Learning#关键术语|42个核心概念入口]]，覆盖训练、网络结构、生成与强化学习。本轮新增21篇概念，原基础缺口的覆盖情况见 [[00 - 首页/建设计划#深度学习基础概念缺口|建设计划]]。

正则化学习入口见 [[00 - 首页/教材归档/DS013 - Introduction to Statistical Learning R#习题归档|ISLR 第 6 章九题]]，另有 [[04 - 统计学习/习题/习题 ML013 - 弹性网络的增广数据表示|ESL 弹性网络补充题]]。Lasso、岭回归、弹性网络与高维回归已有概念页；三道应用题已在 WSL 的 R 中实际运行，[[工具/ISLR/README|环境、结果及有限核验边界]]独立记录。
