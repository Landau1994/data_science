# 数据科学知识库（Data Science）

以**概率论 → 数理统计 → 统计学习／概率推断 → AI**为主线的中文 Obsidian 知识库，同时整理线性代数、优化、因果推断、时序与可复现计算。

## 开始使用

1. 在 Obsidian 中“打开文件夹作为仓库”，选择 `E:\project\math\data_science`。
2. 打开 [[00 - 首页/索引|首页索引]] 与 [[00 - 首页/使用指南|使用指南]]。
3. 从主题导航进入概念、习题和来源，使用 Templater 插入“模板”目录中的模板。

正文与标题为中文；关键概念首次出现标明英文，概念笔记保留英文别名。用于追踪的字段与枚举保持稳定英文值。

## 追踪与模板

- **概念、习题、学习进度**：沿用参考库的标签与元数据驱动方式，动态发现笔记。
- **项目、实验、文献**：记录研究问题、版本和实际结果，关联相关概念。
- **知识图谱**：[[知识图谱/数据科学总览.canvas|数据科学总览]]、[[知识图谱/主题关系.canvas|主题关系]]、[[知识图谱/学习路线.canvas|学习路线]]。
- **解答格式**：统一为 `> [!success]- 解答`，证明范围写在正文。
