# 数据科学知识库（Data Science）

以**概率论 → 数理统计 → 统计学习／概率推断 → AI**为主线的中文 Obsidian 知识库，同时整理线性代数、优化、因果推断、时序与可复现计算。

## 开始使用

1. 在 Obsidian 中“打开文件夹作为仓库”，选择 `E:\project\math\data_science`。
2. 打开 [[00 - 首页/索引|首页索引]] 与 [[00 - 首页/使用指南|使用指南]]。
3. 打开 [[00 - 首页/建设计划|建设计划与验收清单]]，查看本轮完成项与后续顺序。
4. 从主题导航进入概念、习题和来源，使用 Templater 插入“模板”目录中的模板。

正文与标题为中文；关键概念首次出现标明英文，概念笔记保留英文别名。概念的 `source` 属性直接写教材名、章节和印刷页／PDF物理页，使用普通文字；正文保留来源台账链接及核对边界。用于追踪的字段与枚举保持稳定英文值。
